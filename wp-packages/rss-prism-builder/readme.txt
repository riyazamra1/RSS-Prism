== Description ==

RSS Prism Builder adds a visual, responsive drag-and-drop layout builder to WordPress with 60 content, layout, interactive, media, fullwidth, and e-commerce modules.

= Features =

* 60 Divi-style visual modules across Layout, Content, Interactive, Media, Blog/Portfolio/Navigation, Fullwidth, and WooCommerce categories
* Responsive Desktop, Tablet, and Mobile preview modes plus Wireframe structure mode
* Content, Design (typography, gradients, borders, shadows, animations), and Advanced (visibility toggles, custom ID/CSS class) tabs
* Six ready-to-use RSS starter layouts and Global Design System color presets
* Shortcode `[rss_prism_canvas id="123"]` and one-click page publishing

== Frequently Asked Questions ==

= How do I display a builder template on a page? =
Use the "Publish Page" action inside RSS Prism Builder or insert `[rss_prism_canvas id="TEMPLATE_ID"]` into any page or post.

= Does RSS Prism Builder work with any WordPress theme? =
Yes. It works seamlessly with RSS Prism Theme and any standard WordPress block or classic theme.
