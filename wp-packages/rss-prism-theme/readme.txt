A responsive multipurpose WordPress theme with Theme Studio header/footer layout builder and clean accessible templates.

== Description ==

RSS Prism is a lightweight, responsive WordPress theme built by Razeen Smart Solution. It includes Customizer colour, width, header, and footer presets alongside a visual Theme Studio header and footer row organizer.

= Key Features =

* Responsive grid and list archive layouts
* Visual 3-row Header and Footer builder under Appearance > Theme Studio
* Accessible keyboard navigation, skip links, and mobile menu toggle
* WordPress Customizer support for brand accent colours, surface contrast, button shape, and layout width
* Seamless support for pages designed with RSS Prism Builder
